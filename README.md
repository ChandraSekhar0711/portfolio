## Run Locally

Clone the repository:

```bash
git clone https://github.com/ChandraSekhar0711/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
